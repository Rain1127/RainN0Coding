# 固定离线基线

`501811a5c8501b63/baseline.json` 来自 2026-10-27 本地 PR 离线套件实际执行：9 个用例、9 个观测，通过率及断言通过率均为 1.0。它测量离线回放、路由及静态执行，不代表实模型生成质量或线上性能。

默认策略以此为参考，对 case / observation / assertion pass rate 采用零下降门槛。兼容键固定 suite、数据集版本及内容指纹、模型别名和 offline 标志；Prompt 指纹保留在报告中，允许比较 Prompt 修改。

初始基线使用旧版报告字段，未采集的工作区差异和依赖环境不能追补为已采集；本轮最终报告增加了这些字段和源文件清单。Nightly 需要在实模型及向量库可用后重复运行并单独建立兼容基线，缺少基线时门禁明确失败。

基线禁止覆盖；含基础设施异常或质量门禁失败的报告不能晋升。只有缺少基线这一项失败时，可以在审阅报告后初始化基线。
