## P5

- Builder 构建、登记的 Coder 检查及 Chromium 验收共用执行请求和结果。检查支持 typecheck、lint 和单个登记测试目标，单次最多45秒，每任务最多6次，计入有效时间和持久化工具轨迹。
- 候选使用独立 rootless Docker 引擎，容器内 UID 0 映射为宿主非 root 服务账号。每次执行限制1 CPU、512 MiB、128 PID，根文件系统只读，禁用额外能力和新增权限。候选构建在一次性副本运行，只回收经校验的依赖和构建产物；浏览器只读挂载候选。安装依赖经登记的官方 npm 源，禁止生命周期脚本；执行代码与浏览器关闭网络。
- 云端13项包含真实 Node 安装/构建、受限环境、失败分类、超时、取消及 Coder 根据真实检查错误修复。隔离浏览器额外通过1项，涵盖正反断言和外部资源被禁网的未验证状态。仅 Node、Chromium 已完成隔离实测，其他语言运行时按配置报告可用性。
- 宿主 `/proc` 额外挂载会使 rootless 容器无法启动。候选引擎在独立私有挂载命名空间中启动并降至服务 UID，系统其他服务的挂载和 Docker 引擎未切换。
